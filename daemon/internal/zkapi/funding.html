Send funds to your receiving address above, not directly to the vault. Use only the displayed network and billing token. Keep the receiving-address key and the companion’s private note state backed up together. This page never receives either secret.

One private balance is supported at a time. The CLI does not yet provide a private-balance withdrawal command. Do not delete an active balance to add more funds.

Funding transfers and deposits are public Ethereum transactions; they are not anonymous. Inference uses the private note and a verified ephemeral key. This local page loads no third-party scripts. Opening or reloading it does not authorize a transaction.
